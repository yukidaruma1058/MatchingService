ドメイン別の流れ（概要）

  • マスタ：companies を中心に contacts / 取込元紐付け。提案メールの件名・本文は DB テンプレではなくコード内で固定生成（BAT-007 / BAT-009）
  • 取込：Gmail メール振り分け（BAT-001）→ ラベル別取込・AI 要約（BAT-002）→ 過去データ削除（BAT-006）→ talents / projects 登録後にルール採点（BAT-003）
  • マッチング：talents × projects → ルールスコア採点 → matches（match_runs 単位）。LLM 判定は上位候補のみ補助情報として追記
  • 応募：applications で人材×案件の応募状態を管理
  • 送信：実装は outreach_messages / outreach_message_talents / outreach_replies（Gmail スレッドへの返信提案）。下図の proposals / sent_emails は旧案表記
