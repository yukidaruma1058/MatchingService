エラーコード一覧

画面・API・バッチで共通利用するエラーコードと表示メッセージ

画面設計書 バッチ設計書

採番ルール

  • 形式は ERR-xxxx（4桁ゼロ埋め）とし、ERR-0001 から連番で採番する。
  • 画面側・バックエンド側とも同じコードを利用し、API レスポンスには error_code と error_message（利用者向け文言）を含める。
  • 画面側は処理開始前チェックで検知できるものを API 呼び出し前に止め、同じコード・メッセージを表示する。
  • 未知の例外は握りつぶさず、ログには詳細、画面には汎用メッセージを表示する。

メッセージは利用者向け表示文言（API では error_message、ログでも error_message キーで出力）。ログにはエラーコード、機能ID、モジュール名、メソッド名、処理名、対象ID、外部APIレスポンス要約を記録する。ただしメール本文、OAuth token、API キーは出力しない。ダッシュボード等の画面には ERR-xxxx: メッセージ のみ表示し、ログ本文は出さない。
