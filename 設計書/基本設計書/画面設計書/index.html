画面共通の処理開始前チェック

画面側は API 呼び出しや画面遷移の前に以下を必ず確認し、検知可能なエラーは画面で止める。 表示するコードとメッセージは エラーコード一覧 に従う。

タイミングチェック内容エラーコード処理方針
保存・送信前必須入力、形式、文字数、数値範囲ERR-0001〜ERR-0003該当項目を強調し、API 呼び出し前に停止
対象操作前送信対象・マッチング対象・削除対象の選択有無ERR-0004対象選択を促す
検索前検索条件の組み合わせ、日付範囲ERR-0005検索実行前に停止
メール送信前宛先/CC/BCC の入力有無とメール形式ERR-0006送信ボタンを押せない状態にする
ボタン押下時処理中フラグ、二重クリック、同一リクエスト多重送信ERR-0007ボタンを disabled にし、完了まで再実行不可
画面遷移前未保存変更の有無ERR-0008確認ダイアログを表示
API 応答受信時error_code の有無ERR-0011 以降コードに対応するメッセージを表示し、必要に応じて再読み込み・再連携へ誘導

  • 入力・操作 — ボタン・フォーム・バリデーション

  • 参照 DB — 関連テーブル（ER 図）
