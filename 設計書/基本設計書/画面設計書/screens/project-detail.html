SCR-005 案件詳細

案件情報・取込元・要員採点結果・提案

画面イメージ
画面ID: SCR-005URL: /projects/:idSCR-011/012 統合先

1. 画面概要

1 件の案件について、要約案件情報・取込元メール・直近マッチの要員採点結果を表示する。旧 SCR-011/012 の役割（案件別スコア一覧・案件側提案）を本画面に集約する。提案・AI採点は本画面から行う。

2. 画面遷移

遷移元案件一覧、ダッシュボード、人材詳細（採点案件リンク）、メール取込
遷移先案件一覧、人材詳細、企業詳細

3. 表示項目

要約案件情報

必須スキル、配信元会社、単価、勤務地、勤務形態、開始時期、外国籍、商流制限、状態（募集中/終了）、要約

取込元メール

件名、From、ラベル、受信日時（本文表示トグルは設けない）

要員の採点結果（ルールスコア降順）

列内容
選択チェックボックス（AI採点・提案の対象）
順位 / ルールスコア / 帯 / AImatches。スコアは内訳ホバー可
要員人材詳細リンク
スキル案件必須と一致するものを基本表示。その他は「その他(+N)」ホバー
希望単価 / ステータス / 理由talents / outreach・reply / matches.reason

応募人材（設計上・未実装のまま維持）

applications に基づく応募済人材一覧（応募日・状態など）。現状 UI は採点結果（matches）を主表示とする。

4. 操作

  • 選択をAI採点 → POST /api/match-runs/{id}/ai-judge（BAT-004）
  • 選択を案件配信元へ提案 → POST /api/outreach/project-propose（BAT-009）

5. API・参照 DB

API: GET /api/projects/:id、GET /api/projects/:id/matches、POST /api/match-runs/{id}/ai-judge、POST /api/outreach/project-propose

DB: projects, companies, emails, matches, talents, outreach_*
