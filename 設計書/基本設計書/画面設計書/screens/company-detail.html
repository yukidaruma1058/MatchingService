SCR-008 企業詳細

企業情報・担当者の参照（企業マスタは現状 UI 未実装）

画面イメージ
画面ID: SCR-008URL: /companies/:id

1. 画面概要

既存企業の基本情報・担当者一覧を表示する。提案メールの件名・本文は企業ごとテンプレではなく、BAT-007 / BAT-009 のコード内固定フォーマットで生成する（DB の email_templates は持たない）。

2. 画面遷移

遷移元企業一覧、企業追加（登録後）、案件一覧（配信元リンク）、マッチング詳細
遷移先企業一覧、企業情報編集（SCR-018）、担当者一覧、関連案件一覧

3. 表示・編集項目

企業情報（参照）

企業名、区分、ドメイン、既定宛先、関連案件/人材件数

担当者テーブル

氏名、メール、役割（主担当/副担当）— contacts

提案メール本文（参考）

画面上でのテンプレ編集は行わない。実装は次のとおり。

  • 要員への案件提案: api/app/talent_proposal_body.py / batch/BAT-007/talent_propose.py
  • 案件への要員提案: batch/BAT-009/project_propose.py の _build_body
  • 件名: 元メール subject（なければ案件名）。必要に応じて Re: 付与

4. 操作

  • 企業情報を編集 → SCR-018 企業情報編集
  • 担当者を追加 → SCR-017、各行の編集 → SCR-019 担当者情報編集

5. 参照 DB

companies, contacts, projects, talents
