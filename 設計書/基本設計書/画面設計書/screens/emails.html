SCR-015 メール取込

Gmail ラベル付きメールの取込・要約状況

画面イメージ
画面ID: SCR-015URL: /emails

1. 画面概要

Gmail からのメール振り分け・取込バッチの状況を可視化する。手動で即時取込をトリガーでき、各メールの処理状態（未処理・振り分け済・要約済・ルール採点済・LLM判定済）と登録先（人材/案件）を確認する。

2. 画面遷移

遷移元サイドナビ、ダッシュボード（未処理リンク）、人材詳細（元メール）
遷移先人材/案件詳細、案件一覧、設定

3. 表示項目

KPI

本日取込人材/案件の内訳
未処理emails.status=pending 件数
LLM 補助判定system_settings.ai_assist_enabled
次回 cronOfelia スケジュールから算出

取込一覧

受信日時、ラベル（人材/案件）、件名、状態、登録先 ID、詳細リンク

4. 操作

今すぐ取込POST /api/batches/gmail-pipeline で BAT-001 → BAT-002 → BAT-006 → BAT-003 を連鎖起動。ai_assist_enabled が ON なら BAT-004 まで実行
再実行失敗・未処理メールの再処理
設定設定画面へ

5. バッチ処理（参照）

  1. ① BAT-001 メール振り分け: Gmail API で未処理メールを取得し、案件/要員ラベルを付与
  2. ② BAT-002 メール取込: ラベル付きメールを AI で要約・JSON 出力し、talents / projects INSERT
  3. ③ BAT-006 過去データ削除: ingest_data_retention_days を超えた emails を削除（0 でスキップ）
  4. ④ BAT-003 ルールスコア採点: 全案件に対して要員ごとのルールスコアを算出し、matches INSERT/UPDATE
  5. ⑤ BAT-004 LLM 補助判定: 設定 ON なら④完了時、設定 OFF なら画面から手動実行

DB: emails, talents, projects, match_runs, matches, system_settings
