人材・案件・取込・提案ファネルの概況

画面イメージ
画面ID: SCR-001URL: /認証: 将来実装

1. 画面概要

システム全体の状況を把握するホーム画面。KPI カードに加え、期間指定の 供給バランス（積み上げ棒＋企業別）、 ファネル（取込→OK、制約ロス内訳）、 スコア帯別 OK率 で実績分析する。

2. 画面遷移

遷移元サイドナビ（全画面）、ログイン後の初期表示
遷移先人材一覧 / 人材詳細、案件一覧 / 案件詳細、メール取込、企業一覧・企業詳細

3. 表示項目

項目データソース備考

振り分け待ちGmail（source label）GET /api/dashboard/sort-queue
未処理メール / 提案中emails / outreach_messagesKPI カード
供給バランス emails + outreach 積み上げ棒（葉）: 案件・人材未提案 / 案件・人材提案済 / 人材・案件未提案 / 人材・案件提案済 / 振り分け不可。 提案済み判定は現在時点。同 Panel に企業別取込 Top8（案件=distributor / 人材=introducer）の横棒。
ファネル emails → matches → outreach → replies 取込 → 提案可能（最新 match_run で score>0）→ 提案済 → 返信あり → OK。 制約ロス内訳: 外国籍NG / 商流 / その他スコア0。
スコア帯別 OK率 期間内送信提案 × match.score_band × 返信 judgment 横棒。帯未設定は「不明」

期間は 1週間 / 1か月 / 半年 / 1年（画面上部で共有）。データは GET /api/dashboard?range=&end=。
